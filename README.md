# HumanTrace

## Explainable Authorship Intelligence Platform

HumanTrace is an AI-powered writing analysis system that detects AI-generated or AI-assisted text using explainable linguistic, statistical, and machine learning techniques.

Unlike traditional AI detectors that provide only a probability score, HumanTrace analyzes **why** a passage appears machine-generated by examining measurable writing patterns.

---

# Features

## Writing Analysis

HumanTrace analyzes:

- Sentence structure
- Vocabulary diversity
- Writing rhythm
- Repetition patterns
- Syntax patterns
- Readability
- Semantic consistency
- Language model statistics


## Explainable AI Detection

Instead of:

> "82% AI"

HumanTrace provides:

- Highlighted suspicious sentences
- Feature-based explanations
- Confidence scores
- Evidence behind predictions
